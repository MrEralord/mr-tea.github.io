Conceptual Anchor

The Billboard Analogy

Think of print() as a digital billboard. You choose what to display, how items are separated using sep, and what comes after the output using end. Escape sequences are formatting controls that create new lines, tabs or special characters.

Anatomy of print()

Python code 
print("A", "B", "C",
      sep="-",
      end="!")
Exact output 
A-B-C!
Values"A", "B", "C"

The objects that Python displays.

Separatorsep="-"

Text inserted between multiple values. Default: one space.

Endend="!"

Text added after all values. Default: newline \n.

 About \t

                            
\t inserts a horizontal tab and advances to the next tab stop. Its visible
                                width depends on the terminal, editor or environment, so do not treat it as “exactly
                                eight spaces”.

 Pitfalls & Common
                            Errors

                        

                            
 Forgetting Escape in File Paths

                            
print("C:\new\test") interprets \n as a newline and
                                \t as a tab. Use "C:\\new\\test" or, where appropriate,
                                r"C:\new\test".

                        

                        

                            
 Mixing Quote Types Incorrectly

                            
print('It's raining') causes a syntax error. Use
                                print("It's raining") or print('It\'s raining').

                        

                        

                            
 Missing Comma Between Arguments

                            
print("Score:" 95) is invalid. Use print("Score:", 95).

                        

                        

                            
 Concatenating Text and Numbers Directly

                            
"Age: " + 16 causes a TypeError. Use
                                print("Age:", 16) or convert the number with str().

                        

                        

                            
 Forgetting What end Does

                            
end="" or end=" " means the next print() begins on
                                the same line.

                        

                    


                    

                        
 Pro-Tips for Exams

                        

                            
 Output Questions

                            
    
                                
  • Write the output exactly, including spaces, punctuation and line breaks.
    • 
                                
  • Default sep=' ' is one space.
    • 
                                
  • Default end='\n' moves to the next line.
    • 
                                
  • print() with no values outputs only its ending, so the default creates
                                    a blank line.
    • 
                                
  • \t moves to a tab stop; do not assume exactly eight spaces.
    • 
                                
  • With several print() calls, trace where the previous end
                                    leaves the cursor.
    •

 Self-Check Quiz

                        

                            
1. What is the default value of sep?

                            
A single space:
                                ' '.

                        

                        

                            
2. What does \t do?

                            
It inserts a horizontal
                                tab and advances to the next tab stop.

                        

                        

                            
3. What is the output of
                                print("A", "B", "C", sep="-", end="!")?

                            
A-B-C!
                            

                        

                        

                            
4. How do you place a literal backslash inside a normal Python
                                string?

                            
Use \\.
                            

                        

                        

                            
5. What happens with print("Hello\nWorld")?

                            
Hello is
                                printed on one line and World on the next.
