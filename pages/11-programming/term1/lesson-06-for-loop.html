For Loop & Range

A for loop takes values from an iterable one at a time and runs the loop body for each value. With range(), Python can generate predictable integer sequences using a start, stop and step.

Conceptual Anchor

The Measuring Tape Analogy

range(start, stop, step) is like walking along a measuring tape. start is where you stand first, step is how far you move each time, and stop is the boundary you do not include.

Understanding range()

range(2, 10, 3)
2start

The first generated value.

10stop — excluded

The sequence stops before reaching this boundary.

3step

The amount added after each generated value.

Result

range(2, 10, 3) generates 2, 5, 8. The next value would be 11, so the range stops.

Form Meaning Example Values Generated
range(stop) Starts at 0, step 1 range(5) 0, 1, 2, 3, 4
range(start, stop) Starts at start, step 1 range(2, 6) 2, 3, 4, 5
range(start, stop, step) Uses the specified integer step range(0, 10, 2) 0, 2, 4, 6, 8
range(start, stop, step) A negative step counts downward range(5, 0, -1) 5, 4, 3, 2, 1

Critical: stop is excluded

range(1, 5) generates 1, 2, 3, 4. To generate 1 through 5 inclusive, use range(1, 6).

step cannot be zero

range(1, 10, 0) raises ValueError. A zero step could never move toward a stopping boundary.

 Loop Variable Experiment

                        

                            

                                
for i in range(3):
    i = 100
    print(i)

                                
Output: 100 100 100. The assignment changes i during the
                                    current iteration.

                            

                            

                                
for i in range(3):
    print(i)
    i = 100

                                
Output: 0 1 2. At the start of the next iteration, Python assigns the
                                    next value supplied by range().

                            

                        

                        

                            
 Precise rule

                            
Assigning a new value to the loop variable affects it during the current iteration, but
                                it does not change the sequence of values supplied by the for loop.

 Pitfalls & Common
                            Errors

                        

                            
 Stop value is excluded

                            
range(1, 10) ends at 9. Use range(1, 11) when the requirement
                                includes 10.

                        

                        

                            
 Wrong step direction

                            
range(5, 2) and range(2, 5, -1) are empty because the step
                                moves away from the stop boundary.

                        

                        

                            
 Zero step

                            
range(1, 10, 0) raises ValueError.

                        

                        

                            
 range() with floats

                            
range(0.0, 1.0, 0.1) raises TypeError. Standard
                                range() arguments must be integers.

                        

                        

                            
 Modifying the loop variable

                            
Reassigning i affects the current iteration, but the next iteration still
                                receives the next value from the iterable.

                        

                        

                            
 Unnecessary manual update

                            
In a normal for i in range(...) loop, you do not need i += 1.
                                The next value is supplied automatically.
