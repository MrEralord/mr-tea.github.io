While Loop & Flowcharts

A while loop repeats a block of code while a condition remains True. It is especially useful when the number of repetitions is not known in advance. Flowcharts help us design the loop before translating the algorithm into Python.

Conceptual Anchor

The Guard at the Door

A while loop is like a guard checking a condition before each entry. If the condition is True, you enter the loop body. When the body finishes, you return to the guard. If the condition becomes False, you leave the loop.

1. Check condition
2. True → enter body
3. State changes
4. Return and check again
5. False → leave loop
Initialise count = 1
→
Check count <= 5?
→
Body print(count)
→
Update count += 1
After the update, execution returns to the condition. If the condition is False, the loop ends.

Anatomy of a While Loop

count = 1 while count <= 5: print(count) count += 1
1. Initialise count = 1

Create the starting state before the first condition check.

2. Condition count <= 5

The body runs only when this expression is True.

3. Body print(count)

The statements repeated during each iteration.

4. Update count += 1

Changes state so the condition can eventually become False.

More precise rule

Something relevant to the condition must eventually change, otherwise the loop may never terminate.

A while loop can run zero times

Initial value x = 10

The variable starts at 10.

First check x < 5

10 < 5 is False.

Body print(x)

Skipped because the first check is already False.

Output nothing

The body executes zero times.

x = 10 while x < 5: print(x) # No output

                             When Should I Use while?
                        


                        

                            

                                
                                Unknown repetitions
                                
You do not know in advance how many iterations will be needed.

                            


                            

                                
                                Condition-controlled
                                
Repetition continues while a Boolean condition remains True.

                            


                            

                                
                                User-controlled stop
                                
Input determines when the loop finishes.

                            


                            

                                
                                Validation
                                
Repeat until acceptable input is received.

                             Pitfalls & Common Errors
                        


                        

                            
 Infinite Loop

                            

                                If the condition never becomes False, the loop continues indefinitely.
                                Changing a variable is not enough — it must change in a direction that can
                                eventually make the condition False.
                            

                        


                        

                            
 Off-by-One Error

                            

                                < and <= often produce different iteration counts.
                                Trace the first and last successful checks.
                            

                        


                        

                            
 Sentinel Not Updated

                            

                                When a sentinel controls the loop, a new value must be obtained inside
                                the loop body. Otherwise the condition keeps testing the same old value.
                            

                        


                        

                            
 Update Moves the Wrong Way

                            

                                x += 1 is wrong if the loop needs x to decrease toward zero.
                                Always compare the update with the stopping condition.
                            

                        


                        

                            
 Invalid Starting State

                            

                                The condition is checked before the first iteration. A starting value may
                                cause the body to run zero times.
                            

                        


                        

                            
 Numeric Input Still Needs Conversion

                            

                                input() returns str. Convert with int()
                                or float() when the loop compares numeric values.
                            

                        

                    


                    
                    

                        

                             Pro-Tips for Exams
                        


                        

                            
 Loop Tracing Strategy

                            
    
                                
  • Write a trace table with a column for every changing variable and the output.
    • 
                                
  • Check the condition before every iteration, including the first.
    • 
                                
  • Remember that one final False check happens after the last successful iteration.
                                
    • 
                                
  • For flowchart → code, map the decision diamond to the while condition.
                                
    • 
                                
  • Follow the loop-back arrow carefully.
    • 
                                
  • Ask: what changes, and how will that eventually make the condition False?
    •
