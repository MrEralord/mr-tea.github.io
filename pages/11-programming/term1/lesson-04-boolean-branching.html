Boolean Logic & Branching

Programs make decisions by evaluating conditions as True or False. Comparison and logical operators build those conditions, while if, elif and else decide which path the program follows.

Conceptual Anchor

The Traffic Light Analogy

A traffic light is a branching algorithm: IF the light is green → go; ELIF it is yellow → slow down; ELSE → stop. Each decision is based on a condition that evaluates to True or False.

Logical Operators: AND, OR, NOT

and

Both conditions must be True

A and B is True only when A and B are both True.

or

At least one must be True

A or B is True when A is True, B is True, or both are True.

not

Reverse a Boolean value

not True becomes False, and not False becomes True.

Operator Meaning True when… Example
and Both conditions must be True A is True AND B is True (x > 0) and (x < 100)
or At least one condition is True A is True OR B is True, or both (x == 0) or (x == 1)
not Inverts the Boolean value The original condition is False not (x > 10)

 First True Branch Rule

                            

                                In one if / elif / else chain, Python executes
                                the first branch whose condition is True, then skips the rest of that
                                chain.

                            Why Order Matters
                        


                        

                            

                                
Problematic order

                                
if score >= 60:
    print("D")
elif score >= 70:
    print("C")
elif score >= 80:
    print("B")
elif score >= 90:
    print("A")

                                

                                    For score = 95, the very first condition is already True,
                                    so this prints D.
                                

                            


                            

                                
Correct descending thresholds

                                
if score >= 90:
    print("A")
elif score >= 80:
    print("B")
elif score >= 70:
    print("C")
elif score >= 60:
    print("D")
else:
    print("F")

                                
Start with the most restrictive/highest threshold.

                            

                        


                        

                            if / if / if vs if / elif / else
                        


                        

                            

                                
Separate if statements

                                
x = 10

if x > 0:
    print("positive")

if x > 5:
    print("greater than 5")

                                
Both conditions are checked, so both messages can be printed.

                            


                            

                                
One if/elif chain

                                
x = 10

if x > 0:
    print("positive")

elif x > 5:
    print("greater than 5")

                                
The first condition is True, so the elif is not checked.

                             Compound Conditions vs Nested if
                        


                        

                            

                                
Compound condition

                                
if age >= 18 and has_id:
    print("Access granted")

                                

                                    Compact when both conditions are part of one decision.
                                

                            


                            

                                
Nested if

                                
if age >= 18:
    if has_id:
        print("Access granted")

                                

                                    Useful when the second decision belongs inside the first branch.
                                

                            

                        


                        

                            
 Equivalent only in suitable situations

                            

                                These two examples grant access under the same simple condition,
                                but nested structures are more flexible when each level needs its own
                                else or additional processing.
                            

                        


                        

                            Extension: Python chained comparisons
                            

                                
# Standard form
age >= 18 and age <= 65

# Python also allows:
18 <= age <= 65

                             Pitfalls & Common Errors
                        


                        

                            
 = vs ==

                            

                                = assigns a value. == compares two values.
                                Use if x == 5:, not if x = 5:.
                            

                        


                        

                            
 Forgetting the colon

                            

                                if, elif and else
                                headers end with :.
                            

                        


                        

                            
 Indentation matters

                            

                                Python uses indentation to define a block. Use consistent indentation,
                                conventionally four spaces.
                            

                        


                        

                            
 Incorrect elif ordering

                            

                                In threshold problems, place more restrictive conditions first.
                                Otherwise an earlier broad condition may capture the value.
                            

                        


                        

                            
 Incomplete AND condition

                            

                                if x > 5 and < 10: is invalid.
                                Write if x > 5 and x < 10:.
                            

                        


                        

                            
 x == 5 or 10

                            

                                Do not write x == 5 or 10 when you mean two comparisons.
                                Write x == 5 or x == 10.
                            

                        


                        

                            
 Style tip

                            

                                If a variable is already Boolean, prefer
                                if is_logged_in: instead of
                                if is_logged_in == True:.
                            

                        

                    


                    
                    

                        

                             Pro-Tips for Exams
                        


                        

                            
 Exam Strategy

                            
    
                                
  • When tracing a flowchart, follow only one path at a time for the current input.
    • 
                                
  • In an if/elif/else chain, stop after the first True branch.
    • 
                                
  • For and, one False operand is enough to make the whole expression
                                    False.
    • 
                                
  • For or, one True operand is enough to make the whole expression True.
                                
    • 
                                
  • Logical precedence: not before and before or.
                                
    • 
                                
  • Draw a small truth table when a compound Boolean expression is difficult to trace.
                                
    • 
                                
  • A flowchart diamond represents a decision condition.
    •
