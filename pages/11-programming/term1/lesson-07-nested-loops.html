Nested Loops

A nested loop is a loop inside another loop. The inner loop completes all its iterations for each single iteration of the outer loop. Nested loops are useful for rows and columns, coordinate grids, tables, 2D structures and pattern generation.

Conceptual Anchor

The Clock Analogy

Think of a clock. The minute hand behaves like the inner loop: it completes many values before the hour hand, the outer loop, moves to its next value. Then the minute hand starts its cycle again.

Anatomy of Nested Loops

for i in range(3): # outer loop for j in range(4): # inner loop print(i, j) # body
for i in range(3)Outer loop

Controls the slower-changing dimension: usually rows, groups or larger cycles.

for j in range(4)Inner loop

Runs from start to finish for every single outer-loop value.

print(i, j)Body

Runs once for every valid pair of outer and inner values.

Key Rule

For every single value of i, the inner loop runs completely from start to finish. Only after that does i move to its next value.

Trace Tables for Nested Loops

Recommended tracing method

Use one row for every execution of the innermost body. Record every changing loop variable, any calculated value, and the output.

1. Worked Trace Table Example

for i in range(2): for j in range(3): x = i + j print(x)

What the table reveals

i changes 0 → 1, while j runs 0 → 1 → 2 for each value of i. When i becomes 1, j resets to 0.

Fixed vs Dependent Inner Ranges

Fixed inner range

for i in range(3):
    for j in range(4):
        ...
3 × 4 = 12 body executions

Dependent inner range

for i in range(1, 6):
    for j in range(i):
        ...
1 + 2 + 3 + 4 + 5 = 15

Important rule

Multiplying outer_count × inner_count works when the inner loop has the same number of iterations every time. With a dependent range, add the inner-loop counts for each outer value.

 More Nested-Loop Structures
                        


                        

                            

                                
for outside,
                                    while inside

                                
for i in range(3):
    j = 0

    while j < 2:
        print(i, j)
        j += 1

                                
Nested loops do not have to be two for loops. The same outer/inner rule
                                    still applies.

                            


                            

                                
One outer
                                    loop, multiple inner loops

                                
for i in range(1, n + 1):
    for s in range(n - i):
        print(" ", end="")

    for j in range(1, i + 1):
        print(j, end="")

    print()

                                
Both inner loops execute in sequence for every value of the outer variable.

                            

                        


                        

                            Same Variable Experiment

                        

                            

                                
for i in range(3):

    for i in range(2):

 Pitfalls & Common
                            Errors

                        

                            
 Reusing the same loop variable

                            
The inner loop reassigns the same variable name during its execution. This makes the
                                current outer value unavailable inside/after the inner loop body. Prefer distinct names
                                such as i/j or row/col.

                        

                        

                            
 Misplaced print()

                            
For row-based patterns, the blank print() used for a new line normally
                                belongs inside the outer loop but after the inner loop.

                        

                        

                            
 Multiplying counts when the range is dependent

                            
outer × inner only works for a fixed inner count. If the inner range depends
                                on the outer variable, add each inner count.

                        

                        

                            
 Performance grows quickly

                            
1000 outer iterations × 1000 inner iterations = 1,000,000 body executions. Three nested
                                loops of 100 each also produce 1,000,000 executions.

                        

                    


                    

                        
 Pro-Tips for Exams

                        

                            
 Nested-Loop Strategy

                            
    
                                
  • Identify the outer variable and inner variable first.
    • 
                                
  • Trace the full inner loop for the first outer value.
    • 
                                
  • When the inner loop is exhausted, reset it and move to the next outer value.
    • 
                                
  • For fixed inner ranges, total body executions can be found by multiplication.
    • 
                                
  • For dependent inner ranges, add the number of inner iterations for each outer value.
                                
    • 
                                
  • For pattern questions, identify the number of rows and what changes on each row.
                                
    • 
                                
  • Use a trace table when more than one variable changes.
    •
