Input & Arithmetic Operations

Programs become useful when they can receive data, process it and produce a result. Python's input() function reads keyboard input, while arithmetic operators such as +, //, % and ** allow programs to solve numerical problems.

Conceptual Anchor

The Smart Calculator Analogy

A program is like a smart calculator. input() is the keyboard, arithmetic operators are the calculation buttons, and print() is the display. The important difference is that Python must also know whether the user's input should remain text or be converted to a number.

Input 15 User enters data.
Read input() Python receives text.
Convert int("15") Text becomes a number.
Process 15 * 2 Arithmetic operation.
Output 30 Result is displayed.

Anatomy of input()

age = int(input("Enter age: "))
1. Prompt "Enter age: "

Text shown to the user.

2. Read input(...)

Receives keyboard input as str.

3. Convert int(...)

Converts valid integer-form text to int.

4. Store age =

The integer value is assigned to the variable.

# input() always returns a string name = input("Enter your name: ") age_text = input("Enter your age: ") # Convert input when numeric operations are needed age = int(input("Enter your age: ")) price = float(input("Enter the price: ")) # Multiple inputs x = int(input("x = ")) y = int(input("y = "))

The Division Family: / vs // vs %

/ Real division 17 / 5 = 3.4 The quotient as a floating-point result.
// Floor division 17 // 5 = 3 The mathematical floor of the quotient.
% Modulo 17 % 5 = 2 The remainder associated with floor division.

Relationship

For positive integers: dividend = divisor × (dividend // divisor) + (dividend % divisor). Example: 17 = 5 × 3 + 2.

Operator Toolbox

n % 2 Even / odd remainder

0 means divisible by 2; 1 is the usual remainder for positive odd integers.

n % 10 Last digit

For a positive base-10 integer, gives the units digit.

n // 10 Remove last digit

Useful when processing positive decimal integers digit by digit.

minutes // 60 Whole hours

Calculates how many complete hours fit in a number of minutes.

minutes % 60 Remaining minutes

Calculates what remains after removing complete hours.

1 Remainder First — No Branching Needed Yet

number = int(input("Number: ")) remainder = number % 2 print("Remainder:", remainder) # For positive integers: # remainder 0 → even # remainder 1 → odd

                             Pitfalls & Common Errors
                        


                        

                            
 Division by Zero

                            

                                x / 0, x // 0 and x % 0
                                raise ZeroDivisionError.
                            

                        


                        

                            
 Forgetting to Convert input()

                            

                                input() returns a string. Therefore
                                input("Number: ") + 5 attempts to combine str
                                and int and raises TypeError.
                            

                        


                        

                            
 Invalid Numeric Input

                            

                                If int(input(...)) receives text such as
                                "hello", conversion raises ValueError.
                            

                        


                        

                            
 / Returns a Float

                            

                                In Python 3, 10 / 2 gives 5.0,
                                not integer 5.
                            

                        


                        

                            
 // Means Floor Division

                            

                                It is not simply “remove the decimal part”.
                                This distinction matters for negative values:
                                -7 // 2 == -4.
                            

                        


                        

                            
 % Means Remainder, Not Percentage

                            

                                17 % 5 means the remainder after division, which is 2.
                            

                        


                        

                            
 ** Is Power — Not ^

                            

                                Use 2 ** 3 for exponentiation.
                                In Python, ^ has a different meaning (bitwise XOR).
                            

                        

                    


                    
                    

                        

                             Pro-Tips for Exams
                        


                        

                            
 Must-Know

                            
    
                                
  • input() returns a string.
    • 
                                
  • Use int() or float() when arithmetic is required.
    • 
                                
  • // and % often appear in digit and time-conversion
                                    problems.
    • 
                                
  • For positive integers, n % 2 helps determine even/odd.
    • 
                                
  • n % 10 gives the last decimal digit of a positive integer.
    • 
                                
  • n // 10 removes the last decimal digit of a positive integer.
    • 
                                
  • Use ** for exponentiation, not ^.
    • 
                                
  • Apply operator precedence carefully when tracing expressions.
    •
