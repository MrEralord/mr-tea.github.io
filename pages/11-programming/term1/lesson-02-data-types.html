Data Types & Type Conversion

Every value in Python has a type. The type determines how Python interprets the value, what operations are possible, and how the value behaves in expressions. This lesson focuses on four basic types: int, float, str and bool, plus conversion between them.

Conceptual Anchor

The Container Analogy

Think of data types as different types of containers. A measuring cup stores a number, an envelope stores text, and a light switch stores one of two logical states. Conversion changes how Python represents a value — but only when that value can sensibly be converted.

100 int
≠
"100" str

Same characters, different behaviour

100 + 200 gives 300, while "100" + "200" gives "100200". The type controls the meaning of the + operation.

Python Type Atlas

int

Integer

Whole numbers without a decimal point.

42 -7 0 Typical use: age, quantity, counter, index.
float

Floating-point number

Numbers that contain a decimal component.

3.14 -0.5 2.0 Typical use: temperature, measurement, price.
str

String

A sequence of characters stored as text.

"Hello" 'A' "123" Typical use: names, messages, IDs, text input.
bool

Boolean

A logical value with only two possibilities.

True False Typical use: status flags, conditions, yes/no states.

age_text = input("Enter your age: ")

print(type(age_text))   # <class 'str'>

# Convert before arithmetic
age = int(age_text)

print(age + 1)

# Common compact form
age = int(input("Enter your age: "))

                             Pitfalls & Common Errors
                        


                        

                            
 Invalid String Conversion

                            

                                int("hello") and int("3.14") raise
                                ValueError. The text must have a valid integer form for direct
                                conversion with int().
                            

                        


                        

                            
 "100" Is Not 100

                            

                                "100" + "200" gives "100200",
                                while 100 + 200 gives 300.
                            

                        


                        

                            
 input() Returns str

                            

                                x = input("Number: ") gives text.
                                Use x = int(input("Number: ")) when an integer is needed.
                            

                        


                        

                            
 bool("False") Is True

                            

                                Any non-empty string is truthy in this context, even strings such as
                                "False" and "0".
                            

                        


                        

                            
 int() Does Not Round

                            

                                int(7.9) gives 7.
                                It truncates toward zero rather than rounding to the nearest integer.
                            

                        


                        

                            
 / Returns float

                            

                                10 / 2 gives 5.0 in Python 3,
                                so type(10 / 2) is float.
                            

                        


                        

                            
 String Repetition Is Valid

                            

                                "5" * 3 gives "555".
                                The left operand is a string, so Python repeats the text.
