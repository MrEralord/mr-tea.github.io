Knowledge Retrieval

Let's Recall

Before jumping into CSS types, make sure you can answer these core questions:

  • What does CSS mean? (Cascading Style Sheets - it separates HTML content from design).
  • Why are identifiers (ID) and classes used? (To target specific elements or groups of elements for styling without affecting the whole page).

The 3 Types of CSS Implementation

There are three ways to apply CSS to an HTML document. The best method depends on the scope of the project and how many pages need to share the design.

Comparison Chart (Carousel Task Summary)

Type Application Scope Advantages Disadvantages
Inline CSS Using the style attribute directly inside HTML tags. A single specific element. Highest priority. Good for quick, temporary overrides. Mixes content with design. Very hard to maintain across a site.
Internal CSS Using the <style> tag inside the <head> section. A single HTML document. Does not require uploading extra files. Keeps styles grouped per page. Cannot be shared across multiple pages. Increases HTML file size.
External CSS Placing styles in a separate .css file and linking it via <link>. The entire website (multiple pages). Clean HTML, full reusability, easy to maintain globally, faster loading (caching). Requires an extra HTTP request to fetch the file (minor performance impact).

Practical Tasks

Complete the following tasks independently to practice applying CSS. Note: Create a folder for these tasks and use your code editor.

1 Task 1: Inline CSS

Goal: To use inline CSS directly inside elements.

  • Open a newly created HTML document.
  • Add an <h1> element with the text "Welcome".
  • Apply inline styles to this heading to set: Text color (blue), Font size (36px), and Top padding (20px).
<h1 style="color: blue; font-size: 36px; margin-top: 20px;"> Welcome </h1>

2 Task 2: Internal CSS

Goal: To use internal CSS using the style tag.

  • Inside the <head> tag, add the <style> tag.
  • Define styles for <h2>: text color – green, font size – 24 pixels.
  • Define styles for <p>: font – italic, size – 16 pixels.
<head> <style> h2 { color: green; font-size: 24px; } p { font-style: italic; font-size: 16px; } </style> </head>

3 Task 3: External CSS

Goal: To link and use an external CSS file.

  • Create a new file and save it as styles.css.
  • In this file, define styles for <h3>: color – red, size – 20 pixels.
  • Define styles for <button>: background – light blue, text color – white, padding – 10 pixels.
  • Save the HTML page, and link the external CSS file to it using the <link> tag in the head.
/* Inside styles.css */ h3 { color: red; font-size: 20px; } button { background-color: lightblue; color: white; padding: 10px; }

4 Task 4: Combining CSS Types

Goal: To combine all three types of CSS and observe the cascading priority.

  • Open your HTML document.
  • Inside the <head>, include the external CSS link.
  • Add internal CSS to style the <h1> heading (e.g., color: purple).
  • Insert elements in the body that utilize inline, internal, and external styles simultaneously.
<head> <link rel="stylesheet" href="styles.css"> <style> h1 { color: purple; } </style> </head> <body> <h1>Home page</h1> <h2 style="color: orange;">Subheading</h2> <p>This is an example paragraph.</p> </body>

Plenary & Reflection

Critical Analysis: Which CSS method is considered the most efficient for building a multi-page website, and why?

External CSS. It allows developers to control the design of the entire website from one single file, enforcing consistency, cleaner HTML code, and much faster loading times because the browser caches the CSS file.
