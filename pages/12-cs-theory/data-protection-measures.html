Data Protection Measures

Computer systems use several layers of protection because no single security measure can stop every threat. This lesson focuses on three important measures: firewalls, encryption and biometrics.

Conceptual Anchor

The Secure Building Analogy

Imagine confidential data stored inside a secure building. A firewall is the security checkpoint controlling what may enter or leave. Biometrics checks who is trying to enter. Encryption is like keeping the documents in a coded safe so stolen data is unreadable without the correct key.

Measure Main purpose Typical protection
Firewall Controls network traffic according to security rules Unauthorised or suspicious network connections
Encryption Transforms readable data into ciphertext Confidentiality if data is intercepted or stolen
Biometrics Uses physical or behavioural characteristics to authenticate a person Unauthorised access by someone who cannot provide the biometric characteristic

Defence in depth

These measures solve different security problems. A strong system normally combines several measures rather than relying on only one.

Firewall

A firewall monitors incoming and outgoing network traffic and applies a set of security rules to decide whether traffic should be allowed or blocked.

  • Can be implemented as software, hardware or a combination of both.
  • Checks network traffic against configured rules.
  • Can block unwanted or suspicious connections.
  • Helps separate a trusted internal network from less trusted networks such as the Internet.

1 Firewall Gate

The firewall does not decide whether a person is trustworthy. It decides whether network traffic matches the configured rules.

Firewall ≠ antivirus

A firewall controls network traffic. Antivirus software scans for malicious software. They perform different jobs and may be used together.

Encryption

Encryption converts readable plaintext into unreadable ciphertext using an encryption algorithm and a key. The correct decryption process and key are needed to recover the original plaintext.

If ciphertext is stolen or intercepted, the attacker should not be able to recover the original plaintext without the correct key.

Type Keys Main idea

Encryption does not prevent theft

Encryption protects the confidentiality of data. It does not physically stop a device being stolen and it does not replace backups or access control.

Biometrics

Biometric authentication uses measurable physical or behavioural characteristics of a person, such as a fingerprint, face, iris or voice pattern.

3 Biometric Authentication

Capture Fingerprint, face, iris or voice
Template Convert characteristic into digital features
Compare Captured template vs stored template(s)
MATCH
Access granted Biometric comparison accepted
NO MATCH
Access denied Biometric comparison rejected

The system usually compares a stored biometric template, not a simple image of the fingerprint or face.

Verification vs Identification

Verification is a 1-to-1 comparison: “I claim to be Alice — does this fingerprint match Alice's stored template?”

Identification is a 1-to-many comparison: “Whose biometric is this? Compare it with many stored templates.”

Verification or Identification?

Choose the correct biometric process.

Biometrics ≠ password

A password is something a user knows. A biometric is based on something the user is or a measurable behavioural characteristic.

Extension

Digital signatures and digital certificates

A digital signature can be used to support authenticity and integrity. In common public-key systems, a hash of the message is signed using the sender's private key and verified using the corresponding public key.

A digital certificate links a public key to an identity and is normally issued or signed by a trusted certificate authority.

Why this is extension

These concepts are useful, but the core learning objective of this lesson is the description of protection measures such as firewalls, encryption and biometrics.

Common Pitfalls

Firewall ≠ antivirus

A firewall filters network traffic. Antivirus software detects, quarantines or removes malicious software.

Encryption ≠ authentication

Encryption protects confidentiality by making data unreadable. Authentication checks identity.

Verification ≠ identification

Verification compares one claimed identity with one stored template. Identification searches many stored templates to determine identity.

One measure is not enough

A firewall cannot make stolen files unreadable, and encryption cannot decide whether network traffic should be allowed. Different controls solve different security problems.

Exam Practice

Q1: A school stores confidential examination files on a network server. Describe how a firewall could help protect the system. [2]

Reveal marking points
Monitors/filters incoming and outgoing network traffic. [1] Applies security rules to allow legitimate traffic and block unauthorised/suspicious connections. [1]

Q2: Explain how encryption could protect confidential files if the storage device is stolen. [2]

Reveal marking points
The files are stored as unreadable ciphertext. [1] Without the correct decryption key, the thief should not be able to understand the original data. [1]

Q3: A member of staff unlocks a computer by claiming an identity and providing a fingerprint. Describe how biometric verification is used. [2]

Reveal marking points
The captured fingerprint is converted/processed as a biometric template. [1] It is compared with the stored template for the claimed identity in a 1-to-1 comparison. [1]

Q4: A hospital uses a firewall, encryption and biometric authentication. Explain why using all three provides stronger protection than using only one. [3]

Reveal marking points
Firewall controls network traffic / blocks unauthorised network connections. [1] Encryption protects confidentiality of stolen or intercepted data. [1] Biometrics authenticates users before access is granted; the measures protect against different risks. [1]
