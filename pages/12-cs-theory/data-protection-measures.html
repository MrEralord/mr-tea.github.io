Data Protection Measures

Academic revision + individual exam practice
Learning objective:
Describe data and computer-system protection measures such as physical protection, inter-network screens, information encryption, biometrics and protection against computer viruses.
CONFIDENTIALITY
Only authorised users should be able to access sensitive data.
INTEGRITY
Data should remain accurate, valid and protected from unauthorised or accidental change.
AVAILABILITY
Authorised users should be able to access data and systems when required.
Exam habit: Always connect threat → protection measure → how it works → purpose.

1. Physical protection

THREATS
  • theft of devices or storage media;
  • fire or flood;
  • power failure or power surge;
  • unauthorised physical access;
  • mechanical damage to storage devices.
MEASURES
  • locks and secure server rooms;
  • controlled access and alarms;
  • UPS and surge protection;
  • fire/water detection;
  • off-site or cloud backup.
Exam-standard sentence: An off-site backup protects against site loss because a separate copy remains available even if the original equipment is destroyed by fire.
Avoid: “Fire is a protection measure.” Fire is a threat; backup/fire protection is the measure.

2. Firewall / inter-network screen

A firewall monitors and filters incoming and outgoing network traffic according to predefined security rules.

Incoming / outgoing traffic
packet headers contain source/destination information
→
Firewall rules
compare packet information with configured rules
→
Decision
ALLOW permitted traffic
DENY unauthorised or malicious traffic
For a 2-mark “Describe” answer:
MP1: monitors/filters network traffic using predefined rules.
MP2: allows permitted traffic and blocks unauthorised/malicious traffic.

3. Information encryption

Encryption converts readable data (plaintext) into an unreadable coded form (ciphertext) using an algorithm and key.

Plaintext
Readable original data
→
Algorithm + key
Encryption process
→
Ciphertext
Unreadable without the correct key
2-mark structure:
Process: plaintext/data is converted into ciphertext/coded form using an algorithm and key.
Purpose: unauthorised users cannot understand the data without the correct key; confidentiality is protected.
Too vague: “Encryption makes data safe.” This does not describe the process or the purpose clearly enough.

4. Biometrics

Biometric systems use unique physical or behavioural characteristics to verify or identify a person.

PHYSICAL

fingerprint • iris • face • retina • hand geometry

BEHAVIOURAL

voice • signature • keystroke pattern • gait

→
2. Compare
with stored biometric template
→
3. Decision
match → access
no match → reject
Verification (1:1)
Checks whether a person is who they claim to be by comparing a live sample with that user’s stored template.
Identification (1:many)
Searches many stored templates to determine whose sample was captured.

5. Computer virus and antivirus protection

THREAT

Computer virus

Malicious code that can infect files or systems, replicate, corrupt data or disrupt normal operation.

PROTECTION

Antivirus / anti-malware

Scans files and system activity, detects known or suspicious malicious code, and can quarantine or remove it.

Useful exam terms: scan • virus signatures • suspicious behaviour • detect • quarantine • remove • updates.
Do not confuse: a virus is the threat; antivirus software is the protection measure.

6. Data security vs data integrity

Data securityData integrity
Protects data from unauthorised access, disclosure, loss, damage or attack. Ensures data remains accurate, valid and not improperly altered.
Examples: access control, firewall, encryption, biometrics. Examples: validation, permissions, checks, controlled updates.
For “State two differences [2]”: write two separate comparison points.

Difference 1: Data security deals with protection of data, whereas data integrity deals with validity/accuracy of data.
Difference 2: Data security prevents unauthorised access, whereas data integrity helps prevent incorrect data / human error during data entry.
INDIVIDUAL EXAM PRACTICE

Work independently. Use precise academic terminology.

Q1 — Past examination question (2025)
[2]

Describe how encryption keeps sensitive information secure.

Mark Scheme — Q1

1 mark
Process / coding: describes that encryption converts data/plaintext into coded or unreadable form (ciphertext), using an encryption algorithm and/or key.
1 mark
Purpose: explains that encryption protects confidentiality / secures data while it is transmitted because unauthorised users cannot understand it without the correct key.
Accepted evidence: “converts plaintext into ciphertext”; “uses an algorithm and key”; “cannot be understood without the correct key”; “protects confidentiality”.
Common error: “It makes data safe.” → too vague; no process and no clear purpose.
Full-mark model answer:
Encryption converts plaintext into ciphertext using an algorithm and key. This protects confidentiality because unauthorised users cannot understand the encrypted data without the correct key.
Self-mark: ____ / 2
Q2 — Exam-style question
[2]

Describe how a firewall protects a computer network.

Mark Scheme — Q2

1 mark
Monitoring/filtering: states that a firewall monitors or filters incoming and/or outgoing network traffic using predefined security rules.
1 mark
Decision/protection: states that permitted traffic is allowed and unauthorised/malicious traffic is blocked.
Accepted evidence: “filters packets/traffic”; “compares traffic with predefined rules”; “allows authorised traffic”; “blocks unauthorised or malicious traffic”.
Common error: “A firewall protects the network.” → names the purpose but does not describe how it works.
Full-mark model answer:
A firewall monitors and filters incoming and outgoing network traffic using predefined security rules. It allows permitted traffic and blocks unauthorised or potentially malicious traffic.

Q3 — Exam-style question
[2]

A company uses fingerprint recognition to control access to confidential files. Describe how the biometric system verifies a user.

Mark Scheme — Q3

1 mark
Capture / compare: states that the system captures a live fingerprint/biometric sample and compares it with biometric reference data.
1 mark
Verification: states that the live sample is compared with the claimed user’s stored biometric template and access is granted if there is a sufficient match.
Accepted evidence: “captures live fingerprint”; “compares with stored template”; “one-to-one comparison”; “match → verify/grant access”.
Common error: saying only “fingerprint is scanned” → this gives no comparison/verification step.
Full-mark model answer:
The system captures the user’s live fingerprint and compares it with the stored fingerprint template for the claimed identity. If the samples match sufficiently, the user is verified and access can be granted.
Self-mark: ____ / 2
Q4 — Past examination question (2025)
[2]

State two differences between data security and data integrity.

Mark Scheme — Q4

1 mark
Difference 1: data integrity deals with the validity/accuracy of data, whereas data security deals with protection of data.
1 mark
Difference 2: data security prevents unauthorised access to data, whereas data integrity helps prevent incorrect data / human error during data entry.
Accepted evidence: two DISTINCT comparisons that explicitly relate security to integrity.
Common error: writing one strong comparison and expecting 2 marks. One distinct comparison = 1 mark.
Full-mark model answer:
1. Data security deals with protecting data, whereas data integrity deals with ensuring that data is valid and accurate.
2. Data security prevents unauthorised access, whereas data integrity helps prevent incorrect data caused by human error during data entry.
