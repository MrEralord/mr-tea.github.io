Cloud Computing

The Utility Provider Analogy

A home does not need to build its own power station before using electricity. It connects to a provider and consumes the service when needed. In a similar way, cloud computing allows organisations to access computing resources without owning and operating every physical resource themselves.

Cloud computing is the delivery of computing resources such as processing power, storage, networking, platforms and software over a network, usually on demand.

Potential benefit How cloud technology can provide it
Scalability / elasticity Resources can be increased or reduced as demand changes.
Lower upfront hardware cost An organisation may rent resources instead of purchasing all infrastructure in advance.
Accessibility Cloud services can be reached through a network from different authorised locations and devices.
Faster provisioning New computing resources can often be created without installing new local hardware.
Managed infrastructure The provider can manage some hardware, maintenance and updates, depending on the service model.
Availability / recovery options Cloud architectures can use redundant resources and multiple locations, depending on the chosen service and configuration.

Cloud does not automatically mean secure

Cloud providers may offer strong security tools, but customers still have responsibilities such as configuring identities, permissions, applications and data correctly.

Deployment Models

Deployment model asks:

Where and for whom is the cloud infrastructure provided?

Model Main idea Typical reason to choose it
Public Cloud Cloud infrastructure is provided by a third-party provider and shared across customers using logical isolation. Scalability, convenience and reduced need to own infrastructure.
Private Cloud Cloud infrastructure is dedicated to a single organisation. Greater organisational control, customisation or specific security/compliance requirements.
Hybrid Cloud Combines private and public cloud environments so workloads or data can use both. Keep selected workloads private while using public cloud capacity or services when appropriate.
Extension: Community Cloud

A community cloud is shared by several organisations with common requirements or concerns. It is useful extension knowledge, but the core comparison on this page focuses on public, private and hybrid cloud.

Public Cloud ≠ public data

“Public” describes the deployment model. It does not mean that every customer's data is visible to the general public.

Service Models

Service model asks:

What level of computing service does the provider manage for you?

Model Provider mainly supplies Customer mainly focuses on Example use
IaaS
Infrastructure as a Service		 Virtualised compute, storage and networking infrastructure Operating system, applications and data Renting virtual machines and installing your own software
PaaS
Platform as a Service		 Infrastructure plus a managed application-development/deployment platform Application code and data Deploying a web application without managing the server OS
SaaS
Software as a Service		 A ready-to-use application and its underlying platform/infrastructure Using the application and managing their own content/settings Using an online office or email application through a browser/app

1 Control vs Convenience

IaaS More customer control · more customer management
PaaS Focus on building and deploying applications
SaaS Ready-to-use application · provider manages most of the stack

Deployment model ≠ service model

Public / Private / Hybrid describe how cloud infrastructure is deployed. IaaS / PaaS / SaaS describe the level of service the customer receives.

Electronic Government (E-Government)

E-Government is the use of digital information and communication technologies to provide government information, services and interaction to citizens, businesses and other organisations.

Purpose / function How E-Government can help
Accessibility Services can be available online without requiring every interaction to take place at a physical office.
Efficiency Digital forms, automated checks and connected systems can reduce repetitive manual processing.
Convenience Citizens and businesses can request many services remotely and track results digitally.
Transparency Government information, status information and procedures can be made easier to access.
Reduced paper and travel Digital applications and documents can reduce some paper-based processes and visits to offices.
Communication / participation Digital channels can support notifications, electronic appeals, feedback and interaction with authorities.

2 A Digital Government Service

Citizen / Business Needs a public service or information
Digital channel eGov.kz, eGov Mobile or another authorised platform
Identify & submit Authenticate, complete request and provide required data
Government systems process the request
Government systems Validate data and process the service
Service processing Automated and/or staff-controlled workflow
Digital result Certificate, status, payment result, licence or information

E-Government is more than one website

Kazakhstan's digital-government ecosystem includes channels and systems such as eGov.kz, eGov Mobile, eOtinish, E-license and other connected government platforms.

A major mobile channel for accessing digital public services and documents.

Common Pitfalls

Deployment model ≠ service model

Public/private/hybrid answer one question; IaaS/PaaS/SaaS answer another. Do not mix the two classifications.

Cloud ≠ online storage only

Cloud computing can provide processing, networking, platforms, applications and many other computing resources — not only file storage.

Public Cloud ≠ public data

Public cloud infrastructure can serve many customers while keeping customer resources logically separated.

E-Government ≠ only a website

E-Government includes digital systems, mobile channels, connected information systems and workflows used to deliver public services.

Exam Practice

Q1: Explain one benefit of cloud computing to an organisation. [2]

Reveal marking points
State a valid benefit, such as scalability, reduced upfront infrastructure cost, accessibility or faster provisioning. [1] Link the benefit to how cloud resources are provided, for example resources can be increased when demand rises without first installing equivalent local hardware. [1]

Q2: A company rents virtual machines and installs its own operating systems and applications. Identify the cloud service model and explain your answer. [2]

Reveal marking points
IaaS. [1] The provider supplies the underlying virtualised infrastructure while the customer manages the operating system/applications. [1]

Q3: A company uses a private cloud for sensitive systems and public cloud capacity during periods of high demand. Identify the deployment model and explain your answer. [2]

Reveal marking points
Hybrid cloud. [1] It combines private and public cloud environments/resources. [1]

Q4: Explain two benefits of providing suitable government services electronically. [4]

Reveal marking points
Any two valid benefits with explanation. Examples: Accessibility [1] — users can access suitable services remotely without travelling to an office [1]. Efficiency [1] — digital forms/automated processing can reduce repetitive manual work and speed up suitable processes [1]. Convenience [1] — users can submit requests or obtain information through digital channels [1].
