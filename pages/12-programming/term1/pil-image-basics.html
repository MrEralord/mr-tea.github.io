Conceptual Anchor

The Digital Photo Lab

Pillow is your digital photo lab. Image.open() takes a photo from storage, Image.new() prepares a blank canvas, .size measures it, image methods transform it, and .save() writes the result back to a file.

Image.open()Load an existing image
img.sizeInspect width and height
resize / cropTransform the image
getpixel()Read or change pixels
img.save()Save the final result

Images Are Pixel Grids

Every pixel has a coordinate (x, y). In Pillow, (0, 0) is at the top-left. x increases to the right and y increases downward.

Coordinate System

The coordinate order is always (x, y).

(0, 0)
(3, 2)
(6, 5)

Width × Height

img.size returns (width, height).

width = 640 px height = 360 px
Pythonw, h = img.sizeResultw = 640, h = 360

Important

For an image of size (640, 360), valid pixel coordinates run from x = 0...639 and y = 0...359.

Image Modes

The image mode tells Pillow how pixel values are stored. RGB uses the same Red, Green and Blue channel values from the previous lesson.

"RGB" Red, Green and Blue (142, 87, 201)
"RGBA" RGB + Alpha transparency (142, 87, 201, 128)
"L" 8-bit grayscale 0...255
"1" Binary black and white black / white

Resize, Crop & Rotate

1 Resize

resize() expects a new (width, height) tuple and returns a new image object.

from PIL import Image img = Image.open("landscape.jpg") small = img.resize((320, 180)) small.save("landscape_small.png")

2 Crop

The crop box is (left, upper, right, lower).

Crop Box

(left, upper) (right, lower)

Python

img = Image.open("photo.jpg") box = (100, 60, 420, 260) cropped = img.crop(box) cropped.save("cropped.png")

Crop width = right - left
Crop height = lower - upper

3 Rotate

img = Image.open("photo.jpg") rotated = img.rotate(45, expand=True) rotated.save("rotated.png")

Why expand=True?

At angles such as 45°, corners may fall outside the original canvas. expand=True enlarges the output canvas so the full rotated image can fit.

Worked Examples

1 Open → Inspect → Resize → Save

from PIL import Image img = Image.open("landscape.jpg") print("Mode:", img.mode) print("Size:", img.size) thumbnail = img.resize((320, 180)) thumbnail.save("landscape_thumb.png")

2 Create a New Image

from PIL import Image red_img = Image.new( "RGB", (400, 300), (255, 0, 0) ) red_img.save("red_canvas.png")

output: red_canvas.png

3 Create a Gradient Pixel by Pixel

from PIL import Image img = Image.new("RGB", (256, 256)) for x in range(256): for y in range(256): img.putpixel((x, y), (x, y, 128)) img.save("gradient.png")

R changes with x · G changes with y

4 Convert to Grayscale

from PIL import Image img = Image.open("photo.jpg") gray = img.convert("L") gray.save("photo_gray.png") print(gray.mode) # L

From One Pixel to a Whole Image

Once you can read and write one pixel, nested loops can process every (x, y) position.

6 Invert Every RGB Pixel

from PIL import Image img = Image.open("photo.jpg").convert("RGB") w, h = img.size for x in range(w): for y in range(h): r, g, b = img.getpixel((x, y)) img.putpixel((x, y), (255-r, 255-g, 255-b)) img.save("inverted.png")
(142, 87, 201)
(113, 168, 54)

Each channel becomes 255 - value

Why convert to RGB first?

An input file may use another mode. .convert("RGB") makes each pixel predictable so it can be unpacked as r, g, b.

Common Pitfalls

resize(), crop(), rotate() and convert() return new images

Store the result: small = img.resize((200, 100)).

Width/height vs x/y

img.size is (width, height); pixel coordinates are (x, y).

Wrong crop-box order

Use (left, upper, right, lower), not (x, y, width, height).

Pixel mode mismatch

r, g, b = img.getpixel(...) assumes RGB-like pixels. Convert when necessary: img = img.convert("RGB").

Distorted aspect ratio

Changing a 16:9 image directly to a square changes its proportions. Decide whether stretching is acceptable before resizing.

Self-Check Quiz

Q1: What does Image.open("photo.jpg") do?

It opens and identifies the image file and returns a Pillow image object.

Q2: What does img.size return?

A tuple (width, height) in pixels.

Q3: Where is coordinate (0, 0)?

At the top-left corner of the image.

Q4: What does img.crop((10, 20, 110, 80)) select?

left=10, upper=20, right=110, lower=80; the result is 100×60 pixels.

Q5: Why might you use img.convert("RGB") before pixel processing?

To make each pixel predictable as Red, Green and Blue channel values that can be unpacked as r, g, b.

Q6: Does img.resize((200, 100)) change img itself?

No. Assign the returned copy: small = img.resize((200, 100)).
