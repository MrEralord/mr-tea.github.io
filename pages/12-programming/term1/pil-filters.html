Conceptual Anchor

A Filter Is a Transformation

Think about a photo-editing app. A filter takes an input image, applies a rule, and produces a new output image. Some rules look at neighbouring pixels (blur, sharpen, edges); others modify each pixel directly (negative, grayscale, sepia, warm tone).

Image.open() Load the source image
filter / enhance Apply a transformation
compare Inspect the result
save() Write a new image file

Using ImageFilter

1 Apply and Save a Built-in Filter

from PIL import Image, ImageFilter img = Image.open("photo.jpg") blurred = img.filter( ImageFilter.GaussianBlur(4) ) blurred.save("photo_blurred.png")

2 Chain Filters

from PIL import Image, ImageFilter img = Image.open("photo.jpg") result = img.filter(ImageFilter.SHARPEN) result = result.filter(ImageFilter.FIND_EDGES) result.save("sketch_effect.png")

Order Matters

A filter changes the input for the next filter. SHARPEN → FIND_EDGES does not necessarily produce the same result as FIND_EDGES → SHARPEN.

Why Do Blur and Edge Filters Look at Neighbours?

Many built-in filters do not change a pixel independently. They examine a small neighbourhood around the pixel and combine those values. This small matrix is commonly called a kernel.

Worked Custom Filters

4 Manual Grayscale

from PIL import Image img = Image.open("photo.jpg").convert("RGB") w, h = img.size for x in range(w): for y in range(h): r, g, b = img.getpixel((x, y)) gray = int( 0.299 * r + 0.587 * g + 0.114 * b ) img.putpixel( (x, y), (gray, gray, gray) ) img.save("manual_gray.png")

5 Negative

from PIL import Image img = Image.open("photo.jpg").convert("RGB") w, h = img.size for x in range(w): for y in range(h): r, g, b = img.getpixel((x, y)) img.putpixel( (x, y), (255 - r, 255 - g, 255 - b) ) img.save("negative.png")

6 Sepia

from PIL import Image img = Image.open("photo.jpg").convert("RGB") w, h = img.size for x in range(w): for y in range(h): r, g, b = img.getpixel((x, y)) tr = min(255, int(0.393*r + 0.769*g + 0.189*b)) tg = min(255, int(0.349*r + 0.686*g + 0.168*b)) tb = min(255, int(0.272*r + 0.534*g + 0.131*b)) img.putpixel((x, y), (tr, tg, tb)) img.save("sepia.png")

7 Threshold

Convert the pixel to an intensity. If that intensity is above the threshold, make it white; otherwise make it black.

65 < 128 → BLACK
threshold = 128
205 > 128 → WHITE
from PIL import Image img = Image.open("photo.jpg").convert("RGB") w, h = img.size threshold = 128 for x in range(w): for y in range(h): r, g, b = img.getpixel((x, y)) average = (r + g + b) // 3 if average > threshold: new_color = (255, 255, 255) else: new_color = (0, 0, 0) img.putpixel((x, y), new_color) img.save("threshold.png")

8 Warm Filter

from PIL import Image img = Image.open("photo.jpg").convert("RGB") w, h = img.size for x in range(w): for y in range(h): r, g, b = img.getpixel((x, y)) new_r = min(255, r + 20) new_g = g new_b = max(0, b - 20) img.putpixel( (x, y), (new_r, new_g, new_b) ) img.save("warm.png")

9 Keep Only the Red Channel

from PIL import Image img = Image.open("photo.jpg").convert("RGB") w, h = img.size for x in range(w): for y in range(h): r, g, b = img.getpixel((x, y)) img.putpixel( (x, y), (r, 0, 0) ) img.save("red_only.png")

Keep RGB Values in Range

Standard 8-bit RGB channels use values from 0 to 255. Custom formulas may produce values outside this range, so clamp values before writing them back.

10 Clamp a Calculated Value

# Keep a number between 0 and 255 new_r = min(255, max(0, calculated_r)) new_g = min(255, max(0, calculated_g)) new_b = min(255, max(0, calculated_b))

A Small Helper Function

For larger projects you can write def clamp(v): return min(255, max(0, v)) and reuse it for every channel.

Common Pitfalls

1. filter() Returns a New Image

img.filter(...) does not replace img. Store the result: blurred = img.filter(ImageFilter.BLUR).

2. Unexpected Image Mode

If your custom filter expects r, g, b, first use img = img.convert("RGB").

3. Values Outside 0–255

A custom formula can produce negative values or values above 255. Clamp channel values before calling putpixel().

4. Slow Pixel-by-Pixel Code

Nested for loops are excellent for learning how filters work, but large images may process slowly. Resize a test image while developing.

5. Overwriting Your Original File

During practice, save results under a new filename such as photo_blur.png instead of replacing the source file.

Self-Check Quiz

Q1: Which module provides BLUR, SHARPEN and FIND_EDGES?

ImageFilter from Pillow.

Q2: What does enhancement factor 1.0 mean?

It returns the original appearance for that enhancement property.

Q3: What does ImageEnhance.Color(...).enhance(0) produce?

A grayscale / black-and-white appearance because colour saturation is removed.

Q4: Why might a custom filter begin with convert("RGB")?

So every pixel can be handled consistently as three values: r, g, b.

Q5: What does a threshold filter do?

It compares pixel intensity with a threshold and assigns one result below the threshold and another result above it — commonly black or white.

Q6: What is the negative of (100, 150, 200)?

(155, 105, 55).

Q7: Why is clamping necessary in custom colour filters?

Because standard RGB channel values must remain between 0 and 255.
