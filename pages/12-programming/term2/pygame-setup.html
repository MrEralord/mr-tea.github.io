PyGame Setup & Window

PyGame is a Python library for building 2D applications and games. In this lesson you will connect the library, initialise its imported modules, create the main display Surface, and configure the game window.

What pygame.init() actually does

pygame.init() initialises the imported PyGame modules. You can also initialise individual modules separately, such as pygame.display.init(), but the higher-level pygame.init() is the normal beginner setup.

ModuleNotFoundError?

If Python reports No module named 'pygame', make sure you installed PyGame into the same Python environment/interpreter that runs your program.

Core Setup Commands

Command Purpose in this lesson
import pygame Connect the PyGame package to the Python program
pygame.init() Initialise the imported PyGame modules
pygame.display.set_mode((w, h)) Create the display Surface/window and return the Surface object
pygame.display.set_caption("Title") Set the window title
pygame.quit() Uninitialise PyGame modules when the program is finishing

What about flip() and update()?

pygame.display.flip() and pygame.display.update() make drawing changes visible. They belong naturally with the Game Loop, so we only preview them here and study frame updates in the next lesson.

        if event.type == pygame.QUIT:
            running = False

 Pitfalls & Common
                            Errors

                        

                            
 Wrong set_mode() argument

                            
Pass the size as one pair: pygame.display.set_mode((800, 600)), not two
                                separate positional size arguments.

                        

                        

                            
 Forgetting to store the Surface

                            
set_mode() returns the display Surface. Store it in a variable such as
                                screen because later lessons draw onto it.

                        

                        

                            
 Wrong width / height order

                            
The pair is (width, height).

                        

                        

                            
 Confusing pygame.quit() with program exit

                            
pygame.quit() uninitialises PyGame modules; program termination is a
                                separate Python control-flow issue.

                        

                        

                            
 Window closes immediately

                            
This is not a window-creation error. A usable application needs a loop that keeps
                                processing events; that is the focus of the next lesson.
